### 🎭 [Emotify — AI Emotion Detector](https://github.com/pathaksneha659-blip/Emotion-Prediction)
Flask-based NLP application that analyzes text and predicts emotions with confidence scoring.

**Features:**
- 6-class emotion classification (Joy, Sadness, Anger, Fear, Love, Surprise)
- Confidence scores & probability breakdown
- Text preprocessing with NLTK
- Interactive dashboard

**Tech Stack:** Python • Flask • scikit-learn • NLTK • HTML/CSS/JavaScript • Chart.js

**Live Demo:** [Emotify](https://emotion-prediction-app.vercel.app/)
