- Text preprocessing with NLTK
- Interactive dashboard

**Tech Stack:** Python • Flask • PyTorch • NLTK • HTML/CSS/JavaScript • Chart.js

**Live Demo:** [Emotify](https://emotion-prediction-app.vercel.app/)
